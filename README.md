# PriceWatch — расширение для отслеживания цен

Расширение для браузера на Chromium-движке (Chrome, Edge, Arc, Brave, Yandex
Browser), которое следит за ценами в трёх маркетплейсах: **Ozon**,
**Wildberries** и **Яндекс Маркет**. Вы открываете карточку товара,
нажимаете «★ Следить за ценой» — расширение начинает собирать историю
цен у вас на компьютере. Когда цена реально падает или появляется
скидка, приходит уведомление.

## Чем это отличается от обычных «отслеживателей»

- **Всё локально.** Никаких аккаунтов, регистрации, серверов и
  подписок. История цен хранится в вашем браузере (в IndexedDB) и
  никуда не уходит. Хотите перенести данные — выгружаете JSON, и всё.
- **Никакой телеметрии.** Расширение не собирает статистику использования
  и не отправляет URL внешним сервисам.
- **Три маркетплейса, один интерфейс.** Цены, графики и фильтры —
  единые для Ozon / WB / Я.Маркета. Удобно сравнивать.
- **Метрики, а не только графики.** Расширение считает волатильность,
  глубину типичных скидок, периодичность акций и долю «дней около
  минимума» — это помогает понять, реально ли сейчас выгодно, или
  цена «упала» с искусственно завышенного уровня.

## Возможности

### 🛒 Добавление товара

- Кнопка **«★ Следить за ценой»** автоматически появляется на карточке
  товара в течение 1–2 секунд после загрузки. Кнопка в Shadow DOM,
  стилям сайта не вредит, переживает SPA-переходы между вариантами.
- Альтернатива: щёлкнуть иконку PriceWatch в панели браузера → **«Добавить
  эту страницу»**. Полезно, если вёрстка маркетплейса нестандартная
  и кнопка не появилась.
- На карточках уже отслеживаемых товаров справа внизу виден плавающий
  блок со статистикой (минимум / среднее / текущая) — его можно свернуть.

### 📋 Дашборд (нажать иконку → «Открыть дашборд»)

- **Список товаров** в трёх режимах отображения: компактный список /
  сетка с превью / большие карточки с мини-графиком.
- **Поиск** по названию, бренду, артикулу, тегам.
- **Фильтры:** Все / Избранные / Архив, по маркетплейсам, по коллекциям.
- **Коллекции** — пользовательские группы («Подарки», «Электроника»,
  «Для дома» и т. д.). Один товар может попасть в несколько коллекций.
- **Цветовые акценты** на маркетплейсе (синий Ozon, розовый WB, жёлтый
  Я.Маркет) — опционально, можно отключить.

### 📊 Карточка товара

- График истории цен — пять режимов: линия, область, ступени, столбики
  по дням, диапазон min/max за день.
- Период: 7 / 30 / 90 дней / Всё.
- Сводка: текущая, минимум, максимум, средняя (по времени), разница
  за сутки / неделю / месяц.
- Описание, характеристики, рейтинг, отзывы — берутся прямо с сайта
  маркетплейса.
- **Ценовые тиры** (Ozon, WB): «С банками», «С другими банками»,
  «Без скидки» — что видит сам пользователь маркетплейса, то и
  попадает в карточку.

### 🎯 Метки и заметки

- Избранное (★).
- Архив (скрыть из основного списка, не удаляя).
- Произвольные теги.
- Текстовая заметка.
- **Цель по цене:** «целевая» и «идеальная» цены, под которыми сработает
  уведомление. Дашборд покажет, насколько текущая цена далеко от ваших ориентиров.

### 📈 Метрики и подсказки

- **Волатильность** — насколько сильно цена «прыгает». Низкая (≤ 5%) =
  стабильно, высокая (≥ 15%) = частые акции.
- **Перцентиль за 90 дней** — где сейчас цена в диапазоне трёх месяцев
  (0% = у минимума, 100% = у максимума).
- **Глубина типичной скидки** — медианный процент скидки от «зачёркнутой»
  цены, когда скидка появлялась.
- **Цикл скидок** — медианное число дней между акциями.
- **Доля дней около минимума** — какую часть месяца цена была в пределах
  5% от исторического минимума.
- **Рекомендация:** «Брать», «Подождать», «Возможно поднимут» — короткий
  эвристический совет на основе текущей цены, среднего и истории.

### 🔄 Обновление цен

Три механизма работают вместе:

1. **При заходе на карточку.** Вы открываете товар, расширение тихо
   подтягивает свежую цену. Кулдаун 30 секунд защищает от двойных
   записей при SPA-навигации.
2. **Вручную.** Кнопка «↻» у товара — обновить один. «Обновить все»
   сверху списка — пройтись по всем видимым (с учётом фильтров),
   прогресс в правом нижнем углу.
3. **По расписанию (фон).** Расширение само пересчитывает цены каждые
   N минут или раз в сутки в указанный час:
   - **Wildberries** — через публичный JSON-API маркетплейса
     (быстро, без открытия вкладок).
   - **Ozon и Я.Маркет** — через единственную тихую закреплённую
     вкладку (через минуту простоя закрывается).

Каждая проверка добавляет точку в историю — даже если цена не
изменилась. Так на графике видно, когда товар реально проверялся,
а старые дни автоматически сжимаются (см. «Обслуживание»).

### 🔔 Уведомления

Триггеры (можно комбинировать, можно делать персональные правила
для конкретных товаров):

- Цена ниже X ₽.
- Падение на N% или N ₽ между двумя записями.
- Появилась скидка (раньше не было, теперь есть).
- Снова в наличии после распродажи.
- Исторический минимум.

Дополнительно:

- **Кулдаун** на каждое правило — чтобы не получать десять уведомлений
  подряд об одной и той же скидке.
- **Тихие часы** — диапазон, когда системные всплывашки подавляются
  (журнал ведётся всё равно).
- **Лимит «N уведомлений в час»** — защита от лавины при массовом падении цен.
- **Бейдж на иконке расширения** — количество непрочитанных событий.
- **Журнал в дашборде** («Уведомления» в боковой панели) — история всех
  срабатываний с подробностями.

### 📉 Сводная статистика

Раздел «Статистика» — выжимка по всему списку:

- Сколько товаров отслеживается, разбивка по маркетплейсам и коллекциям.
- Топ самых упавших и подорожавших за 7 / 30 / 90 дней.
- «Сколько вы условно сэкономили» — сумма разниц между текущими ценами и
  историческими минимумами для всего портфеля.

### 🩺 Здоровье парсеров

Диагностическая страница для случаев, когда маркетплейс обновил вёрстку:

- Процент удачных распознаваний за 24 часа / 7 дней по каждому
  маркетплейсу.
- Топ полей, которые чаще всего перестали достаются (цена,
  «старая» цена, описание и т. д.).
- Список последних сбоев с замаскированными URL.
- Красный баннер «Внимание», если успешность ниже 80% за неделю.

### 🎨 Темы

10 готовых палитр + автоматический режим, который следует системной
«светлая / тёмная»:

- Светлые: Default, Cream, Mint, Sky, Rose.
- Тёмные: Slate, Midnight, Forest, Violet, Amber.

Тема применяется ко всему интерфейсу расширения. На сайтах маркетплейсов
тема не меняется — там оригинальный сайт.

### 💾 Резервная копия

В настройках в разделе «Данные»:

- **Экспорт** — всё содержимое (товары, цены, события, коллекции,
  правила, журнал) в один JSON-файл.
- **Импорт** — добавляет недостающее, ничего не перезаписывает. Можно
  слить списки с двух компьютеров.

### 🧹 Обслуживание

Раз в сутки автоматически:

- Сжимает историю цен старше 30 дней — оставляет от каждого дня
  только минимум и закрытие. Свежие 30 дней сохраняются в максимальном
  разрешении.
- Удаляет диагностические записи старше 30 дней.

### 🔒 Приватность

- Никаких внешних серверов, аналитики, телеметрии.
- Доступ только к ozon.ru / wildberries.ru / market.yandex.ru.
- В диагностике URL хранятся без параметров запроса.
- Расширение не имитирует действия пользователя (не кликает «Купить»,
  не добавляет в корзину) и не пытается обходить капчу.

## Установка (для пользователя)

1. Скачайте архив с релизом или соберите сами (см. ниже).
2. Распакуйте папку `dist/`.
3. Откройте `chrome://extensions` (или `edge://extensions`,
   `brave://extensions` и т. д.).
4. Включите «Режим разработчика» (правый верхний угол).
5. «Загрузить распакованное» → выберите папку `dist/`.
6. Иконка PriceWatch появится на панели браузера.
7. Зайдите на любой товар Ozon / WB / Я.Маркета — через секунду под
   заголовком появится кнопка «★ Следить за ценой».

> 💡 На Windows папка с расширением **не должна** содержать кириллицу
> или другие не-ASCII символы (известный баг Chrome). Если у вас путь
> вида `C:\Users\Иван\dist`, создайте junction в ASCII-путь:
> `New-Item -ItemType Junction -Path C:\pricewatch-dist -Target "<полный путь к dist>"` —
> и грузите расширение из `C:\pricewatch-dist`.

## Для разработчика

Manifest V3 · TypeScript 5 (strict) · React 18 · Vite + @crxjs/vite-plugin ·
Dexie 4 · Zustand · Tailwind 3 · Recharts · Vitest.

```bash
pnpm install
pnpm dev         # vite dev с auto-reload расширения
pnpm build       # production-сборка в dist/
pnpm typecheck   # tsc --noEmit
pnpm test        # vitest run (парсеры + repos + services)
pnpm lint        # eslint
```

Архитектурные правила и соглашения — в [`CLAUDE.md`](./CLAUDE.md).
Специфические знания (парсеры маркетплейсов, MV3 lifecycle, Dexie
схема) — в `.claude/skills/`.

### Структура

```
src/
  shared/        # типы, RPC, форматтеры — общее для всех слоёв
  data/          # Dexie + repos (единственный путь к IndexedDB)
  services/      # бизнес-логика (price-history, scheduler, notifications…)
  parsers/       # один subfolder на marketplace + base.ts
  background/    # service worker + handlers
  content/       # per-site content scripts + Shadow DOM injector
  popup/         # action popup
  dashboard/     # full-page UI
  options/       # настройки
tests/           # фикстуры парсеров + unit на fake-indexeddb
```

### Где смотреть, если что-то сломалось

- **Кнопка не появляется**: DevTools → Console, фильтр `[PriceWatch:`.
  Если идут `no anchor element found yet` — каждая 8-я попытка дампит
  DOM-снимок со списком кандидатов на якорь. Это руководство к
  добавлению новых селекторов в `<mp>/index.ts → findAnchor`.
- **SW не отвечает**: `chrome://extensions` → «Inspect service worker».
  В MV3 SW засыпает; первый RPC после идла бывает медленным — это норма.
- **Парсер выдаёт `partial`**: страница «Здоровье парсеров» в дашборде
  покажет, какое поле перестало достаются. Подробности — в таблице
  `parserDiagnostics` (DevTools → Application → IndexedDB → `pricewatch`).
